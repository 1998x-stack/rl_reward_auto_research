第一性原理

三个 Pareto 指标

奖励函数只有同时满足"预测准、学得快、跑得稳"才有价值。三者形成 Pareto 前沿。

task_perf
1.382
任务性能 · 最终策略质量
mean(最后10ep回报) / baseline回报
基于原始 env_reward 计算
task_eff
1.000
样本效率 · 学习速度
AUC(回报曲线) / baseline_AUC
越高=越少样本达到高性能
task_stab
0.831
训练稳定性 · 跨种子一致性
1 − CV(跨seed最终回报)
1.0=完全一致，0.0=高方差
🔒 防作弊设计：所有 Pareto 指标基于原始环境奖励计算，而非 agent 自己设计的奖励函数。Agent 无法通过写 return 999.0 来 hack 指标。 同时输出 reward metrics（基于 agent reward）作为诊断反馈。 详见 ADR 0001 →

编写你自己的奖励函数

reward.py 
from reward import Reward
import numpy as np

class RewardMyDesign(Reward):
    name = "my_design"
    env_id = "CartPole-v1"

    def compute(self, obs, action, env_reward, terminated, truncated, info, env_info):
        pole_angle = abs(obs[2])
        return env_reward - 0.3 * pole_angle

保存后运行 uv run python prepare.py — 自动发现、训练、评估。

迭代策略

Exploit
默认策略
对前沿最优 reward 做局部变异——调整系数、换惩罚项、改塑形形式
Explore
连续丢弃后触发
发明全新奖励结构——不同塑形哲学、跨环境思路迁移
Combine
每 10 次实验
合并两个前沿 reward——加权平均、乘积、条件切换
